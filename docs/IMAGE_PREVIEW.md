# 共享图片预览组件

## 接入

工作台页面通过 `ui-framework.js` 暴露的统一入口按需加载组件和样式：

```javascript
window.personalAI.previewImage({
  url: '/photo/api/tasks/task-id/image?filename=result.png',
  filename: 'result.png',
  prompt: '图片对应的完整提示词',
});
```

组件代码为 `photo_lab/static/image-preview.js`，样式为 `photo_lab/static/image-preview.css`。当前已接入图片生成历史的“放大图片”、图库缩略图和“放大”、标注页的“放大预览”和图片双击。

## 行为

- 上方工具栏包含缩小、放大、适应窗口、原始大小、左右旋转、复制图片和下载。
- 图片加载完成后按当前可用区域等比例显示；显示缩放百分比、原始像素尺寸和旋转角度。支持滚轮缩放、拖动平移及触控双指缩放。
- 缩放只影响预览，不改变导出分辨率。未旋转时下载原文件；旋转后下载完整像素的 PNG，文件名带旋转角度。复制图片同样保留当前旋转方向，以 PNG 写入剪贴板。
- 下方固定展示提示词和独立“复制提示词”按钮。长文本在区域内滚动，缺少提示词时禁用复制。
- 键盘 `+` / `-` 缩放，`0` 适应窗口，`R` 向左旋转、`r` 向右旋转，`Esc` 关闭；关闭后恢复触发按钮焦点和页面滚动。
- 标注页打开预览时暂停自动浏览；预览期间屏蔽标注快捷键，暂停背景图片刷新，不改变标注数据。
- 加载失败时显示错误，关闭按钮和已有提示词仍可用；图片操作在加载期间禁用。剪贴板能力或权限不足时给出失败提示，不伪报复制成功。

## 验收（2026-09-08）

使用应用内浏览器检查桌面 1440×900 和手机 390×844，图片历史、图库、标注页三处入口均成功打开同一组件。

实测缩放、旋转、图片复制成功反馈、提示词复制成功反馈、下载、Esc 关闭和焦点恢复。旋转下载文件已实际落盘，并确认 1200×400 宽图旋转后导出为 400×1200 PNG。

使用临时合成宽图验证长提示词独立滚动、无提示词复制禁用以及 404 加载错误；临时页面在验收后移除。标注页在预览中按右方向键未改变标注统计。拖动和双指手势未纳入本轮自动化实测。

开发阶段在本地验收；发布时还需通过远端真实页面复验三个入口、复制/下载和桌面手机布局，不以本地结果代替部署验收。
