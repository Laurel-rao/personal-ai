## 实现约定

- `admin.py` 为 HTML 统一注入登录上下文和公共资源；API 返回值不受展示样式影响。
- `ui-framework.js` 统一侧栏、标题、账号操作、管理页提示与表格滚动容器。
- `workspace-pages.css` 最后加载，统一浅色背景、白色卡片、绿色主操作、字体、间距、表单和响应式布局。原业务 CSS 继续支撑状态和动态组件。
- `/image` 直接渲染 Photo Lab 模板，不再嵌套 iframe；`/photo/` 与原 API 前缀继续兼容。
- 后台表单仍由 Flask-AppBuilder 生成。数据表可在局部横向滚动；原生表单 table 单独适配手机布局，不套用数据表最小宽度。
- 原页面控件 ID、`data-field` 与 `data-action` 保留。账号和历史仍沿用统一鉴权及用户隔离，不以隐藏菜单代替权限检查。

已检查侧栏收放/手机抽屉、图片单张/批量切换与尺寸预设、历史展开、图库筛选/重置、仿写类别记忆展开/收起、后台用户/角色/菜单表单展示，以及设置页不会自动填入登录凭据。

非空图片交互使用独立临时源码、数据库与三张合成测试图片，不向正式任务文件写入测试记录。验证了历史缩略图实际加载、预览、提示词复制反馈、尺寸/种子复刻、Like 标注统计、随机/顺序切换、自动浏览开始/暂停、图库 Like 筛选，以及视频历史参考图选择和模板回填。

隔离环境的聊天新对话、快捷提示和深度思考开关已检查。快捷提示沿用原行为，会直接提交消息；本次显示“模型没有返回内容”。旧对话页面显示“Qwen 服务不可用”，隔离视频服务连接检查返回 503。以上仅验证了交互和异常状态，**不代表模型或视频生成端到端通过**。
