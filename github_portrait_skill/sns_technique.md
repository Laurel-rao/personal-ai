# 30 項寫實人像技巧矩陣

只挑選 3–5 項。先看場景最需要什麼，再看最容易在哪裡失敗。

| 編號 | 技巧 | 適用訊號 | 提示詞中的可見表達 |
|---|---|---|---|
| ① | SNS 真實存在感 | 日常貼文、個人帳號 | fictional person, authentic social post |
| ② | 手機隨手拍 | Threads、限動、生活照 | smartphone photo, lightly imperfect framing |
| ③ | 生活感背景 | 室內、咖啡店、住家 | used mug, folded jacket, ordinary objects |
| ④ | 自然瞬間 | 避免擺拍臉 | mid-gesture, relaxed expression, unposed |
| ⑤ | 真實膚色 | 美肌感過重 | visible pores, subtle tonal variation |
| ⑥ | 柔和自然光 | 窗邊、陰天、清晨 | soft window light, gentle falloff |
| ⑦ | 淺景深 | 突出人物 | lightly blurred background, optical bokeh |
| ⑧ | 偏離鏡頭視線 | 降低刻意感 | gaze slightly off-camera |
| ⑨ | 日常片段 | 有事件的生活場景 | candid slice-of-life portrait |
| ⑩ | 手機直出色調 | 避免濃重調色 | restrained color, natural white balance |
| ⑪ | 手部完整 | 手持物、托腮、全身 | anatomically coherent hands, relaxed fingers |
| ⑫ | 臉部微不對稱 | 臉部特寫 | subtle natural facial asymmetry |
| ⑬ | 邊界清晰 | 捲髮、蕾絲、逆光 | distinct flyaway hair and fabric edges |
| ⑭ | 光影一致 | 混合光、室內外 | one coherent light direction and shadow logic |
| ⑮ | 預防高風險部位 | 複雜姿勢、遮擋 | simplify pose; make joints and overlaps readable |
| ⑯ | 適度留白 | 專業構圖、封面 | breathing room around subject |
| ⑰ | 電影空氣感 | 故事型畫面 | atmospheric depth, quiet narrative tension |
| ⑱ | 清爽親和 | 個人品牌、生活方式 | approachable mood, clean everyday styling |
| ⑲ | 收藏感 | Instagram 主貼文 | memorable but believable visual motif |
| ⑳ | 一秒世界觀 | 快速滑動場景 | one dominant color or environmental cue |
| ㉑ | 動態牆原生感 | 非廣告貼文 | organic feed-native composition |
| ㉒ | 頭像／封面裁切 | 個人頭像、封面 | clear face and shoulders, safe crop margins |
| ㉓ | 滑動攔截力 | 縮圖觀看 | strong face-background separation |
| ㉔ | 商業留白 | 後製文字 | clean copy space on one named side |
| ㉕ | 受眾共鳴 | 明確族群或品牌 | audience-relevant wardrobe and setting |
| ㉖ | 去 AI 裝飾 | 裝飾過量、皮膚塑料 | no synthetic gloss or ornamental clutter |
| ㉗ | 照片可信度 | 高擬真需求 | physically plausible detail and exposure |
| ㉘ | 全域細節清理 | 近景、高解析檢視 | coherent hair, skin, textile, background detail |
| ㉙ | 防扭曲合成感 | 廣角、肢體交疊 | natural perspective, clean occlusion, no warping |
| ㉚ | 自然優先 | 所有容易過度風格化的場景 | understated finish, realism over glamour |

## 選擇捷徑

| 場景 | 建議起點 |
|---|---|
| 咖啡店日常照 | ③ + ④ + ⑥ + ㉑ + ㉚ |
| 手持商品但不似廣告 | ④ + ⑪ + ⑭ + ㉑ + ㉕ |
| 頭像或個人品牌封面 | ⑤ + ⑫ + ⑱ + ㉒ + ㉔ |
| 夜間街頭人像 | ⑧ + ⑬ + ⑭ + ⑰ + ㉙ |
| 手機自拍感 | ② + ⑤ + ⑩ + ㉓ + ㉚ |

不要照抄捷徑；若場景訊號不同，替換掉不相關項目。
