## 标准结构

使用以下主结构，不为了形式重复同一句控制项：

```text
【参考素材说明】
<每项素材的职责、目标、保持项和排除项；无素材时省略>

【核心创意】
<时长、画幅、主体、地点、事件、风格、特殊运镜或剪辑>

【画面过程描述】
<连续时间轴或 Shot 列表>

【声音】
<对白、环境声、音效、音色、BGM、字幕>

【保持与禁止】
<身份、空间、造型、产品、文字和不得出现的内容>
```

## 参考素材说明

每项素材写成完整契约：

`@素材编号 + 用途 + 控制对象/时间 + 必须保持 + 不得继承`

示例：

```text
@图片1仅作为女主面部身份参考，保持脸型、眉眼、鼻子和嘴部比例；不继承图片背景、姿势和现代服装。
@视频1只提供0-5秒舞剑动作和重心节奏，将动作映射给@图片1中的女主；不继承视频人物身份、场景、服装和声音。
@音频1提供女主对白音色，保留音高、气息和语速；不复用底噪和背景音乐。
```

同一维度不要指定两个来源。若一张图片同时负责身份和服装，明确写出两个职责；若只锁脸，不要默认锁服装。

## 核心创意

用一句话锁定全片：

`时长和画幅 + 主体 + 地点 + 核心事件 + 题材/风格 + 特殊镜头或剪辑`

示例：

```text
15秒、16:9横版写实古装短片，一名年轻剑客在雨夜客栈发现追兵，克制悬疑电影感，以缓慢推进和一次遮挡硬切完成情绪转折。
```

“电影感”“高级”“震撼”不能代替可见设计。补充光源、材质、景别、动作节奏和声音来源。

只补充完成原意所需的环境和执行细节。`舞剑`不自动等于战斗，`奔跑`不自动等于追逐，`对视`不自动等于恋爱；除非用户要求自由扩写，不新增角色、威胁、冲突、品牌、关键道具、对白、反转或结局。

## 画面过程

多镜头使用连续时间段：

```text
0-3秒：景别与空间；主体初始状态；动作；镜头；声音；段末状态。
3-8秒：触发；动作变化；人物反应；切镜或运镜；声音；段末状态。
8-15秒：结果；收束镜头；声音尾点；最终画面。
```

确保动作顺序可读：

`初始状态 → 触发 → 接触/受力 → 主体反应 → 后续动作 → 最终状态`

减少短时间内无法完成的事件。写清屏幕方向、人物站位、视线、道具归属、光线方向和状态累积，避免切镜后人物或物体跳位。

一镜到底时只写连续摄影机和人物运动，不使用“切镜”“反打”“硬切”或瞬时视角跳转。

## 镜头与对白

- 每个 Shot 指定景别、主体、场景、动作和镜头运动。
- 切镜时明确切到哪个既有人物和什么景别，帮助保持身份连续。
- 一次节拍优先使用一个主要运镜；不要同时要求固定机位、环绕、快速推进和拉远。
- 环绕效果优先写成可执行组合，例如 `truck left + pan right` 或 `truck right + pan left`。
- 台词必须给出原文和说话人；画外音、画内说话人以及跨 Shot 的 J-cut/L-cut 要写清。
- 台词长度必须适合镜头时长，并给倾听、停顿、呼吸和反应留时间。
- 需要口型时，让角色嘴型、下颌、呼吸和语速与台词对齐，不要只写“对口型”。

## 声音

H3 快照记录为所有结果原生带声音，因此必须主动说明声音策略：

- 现场声：环境、脚步、衣料、机械、天气等；
- 对白：原文、说话人、画内外位置、情绪、音色来源；
- 音效：与可见触发同步，不能提前；
- BGM：风格、节奏、进入和退出时点；
- 无 BGM：写 `非叙事性音乐：N/A` 和 `不要额外添加背景音乐`；
- 字幕：需要或禁止，文字原文必须逐字给出。

不要同时要求“无背景音乐”和“使用参考音乐”。若只保留参考音频的人声，明确移除哪些音乐和噪声。

## 模式写法

### 文生视频

无参考素材时完整描述人物/物体外观、场景、动作、光线、相机、声音和限制。可用“大全景交代空间—中景承载动作—特写强调结果”组织多镜头。

### 单张首帧或尾帧

明确图片职责和方向：

```text
@图片1是本视频唯一首帧，第一帧保持其构图、主体位置、服装、场景和光线，从该状态自然开始运动。
```

尾帧则从文字描述的初始状态自然收束到图片，不能在最后一瞬凭空跳成尾帧。

### 首尾帧

```text
@图片1是首帧，@图片2是尾帧。保持两帧中的主体身份和空间关系，连续补全中间动作、光影和声音，不切镜，不出现与两帧无关的新主体。
```

### 全能参考

逐项声明人物、物体、场景、动作、运镜、节奏、音色或音乐职责。视频参考不自动拥有身份、背景和声音权限。

### 视频编辑

按 `时间 + 位置 + 目标 + 操作 + 重建要求 + 保护项` 编写。详细规则见 [reference-and-editing.md](reference-and-editing.md)。

## 反例检查

| 问题 | 修正 |
|---|---|
| 上传素材但未写用途 | 为每项素材声明职责和排除项 |
| 一镜到底又列多个切镜 | 删除切镜结构，改为连续运动 |
| 要求角色一致但没有身份图 | 提醒上传人物图并标注身份职责 |
| 只有抽象形容词 | 增加可见主体、场景、动作、光线、镜头和声音 |
| 3秒镜头塞入长对白 | 缩短台词或延长镜头 |
| 音效早于触发 | 按动作因果调整声音时点 |
| 要文字准确但只写“出现标题” | 给出逐字文本；复杂文字可提供图片参考并声明按图像保持 |
| 提示词重复多组全局规则 | 合并权限和禁止项，保留一次最高优先级声明 |
| 根据一个动作擅自扩写新剧情 | 保留动作本身，不新增角色、冲突或故事结果 |
